# 📊 Análise de Dados Financeiros com Power BI

Este repositório contém um projeto de análise de dados financeiros utilizando **Power BI**. O objetivo é explorar, transformar e visualizar dados financeiros para fornecer insights valiosos sobre a performance de uma empresa ou portfólio de investimentos.

## 🛠️ Ferramentas e Tecnologias Utilizadas

- **Power BI**: Ferramenta principal para criação de dashboards e relatórios interativos.
- **DAX (Data Analysis Expressions)**: Utilizado para realizar cálculos e criar medidas personalizadas.
- **Power Query**: Para ETL (Extração, Transformação e Carga) de dados.
- **Fonte de Dados**: Arquivos CSV.

## 📈 Funcionalidades Principais

1. **Dashboards Interativos**: Relatórios financeiros dinâmicos que permitem análise profunda dos principais indicadores financeiros, como receita, despesas, lucro líquido, margem de lucro, entre outros.
   
2. **KPIs (Key Performance Indicators)**: Medidas-chave para acompanhamento da saúde financeira da empresa.
   
3. **Análise Temporal**: Visualizações que mostram o desempenho financeiro ao longo do tempo, com a possibilidade de filtrar dados por ano, trimestre, mês ou outro período específico.

4. **Comparação de Desempenho**: Análise comparativa entre diferentes períodos e categorias, como receita por produto, despesas por departamento, etc.
